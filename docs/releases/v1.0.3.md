# FINORA v1.0.3

- Setoran Tabungan dapat dicatat langsung dari halaman Tabungan atau tombol +, dengan Tabungan Umum tersedia otomatis.
- Total, progress target, riwayat, Dashboard, dan laporan mengikuti transaksi setoran yang sama, termasuk setelah aplikasi dibuka kembali.
- KPI Pengeluaran hanya memuat pengeluaran reguler; saldo mengurangi setoran Tabungan dan Investasi tepat sekali.
- Perhitungan bulanan, edit/hapus setoran, dan persistensi diuji pada web serta Android; build simulator iPhone/iPad divalidasi.

APK debug dapat dipasang untuk pengujian. Pembaruan Android dengan tanda tangan tetap memerlukan keystore release yang sama. Artifact iOS simulator tersedia di GitHub Actions; IPA perangkat memerlukan kredensial penandatanganan Apple.
