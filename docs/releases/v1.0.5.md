# A-Zuha Finance v1.0.5

- Logo AZ asli menjadi sumber ikon launcher, splash, PWA, dan tampilan aplikasi.
- Input tanggal, nominal, pilihan kategori, dan placeholder kini terbaca pada tema terang dan gelap.
- PDF bulanan memuat total, saldo, evaluasi, kategori, dan transaksi. Dokumen kosong dan laporan panjang divalidasi dengan parser PDF.
- Android versionCode 6 dan iOS build 6. APK release ditandatangani dengan keystore permanen dari GitHub Actions Secrets, lalu diverifikasi dengan `apksigner`.

Package ID Android tetap `id.fahmidjawas.keuanganrumah`. Untuk pindah dari APK debug lama dengan sertifikat berbeda: buat backup terenkripsi di aplikasi lama, salin ke lokasi aman, verifikasi backup dapat dibuka pada perangkat terpisah, lalu uninstall APK debug, pasang APK release, dan pulihkan backup. Jangan uninstall sebelum backup terverifikasi. Pembaruan release berikutnya harus memakai sertifikat yang sama. IPA iPhone/iPad hanya tersedia jika kredensial signing Apple tersedia.
