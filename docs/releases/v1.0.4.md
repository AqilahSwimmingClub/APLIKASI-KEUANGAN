# A-Zuha Finance v1.0.4

- Nama tampilan aplikasi dan nomor versi diperbarui, sementara ID paket Android/iOS dan data vault tetap.
- Login portrait, respons keyboard, dan fokus input diperbaiki.
- Biometrik native Android/iOS kini dapat melepas kunci vault yang tersimpan aman setelah diaktifkan pada perangkat; password dan PIN tetap menjadi fallback.
- APK release resmi hanya dipublikasikan jika keystore asli telah tersedia dan tanda tangannya lolos verifikasi. APK debug dari runner lain tidak dapat dijadikan pembaruan terjamin.

Sebelum memasang di atas aplikasi lama, cocokkan fingerprint sertifikat APK lama dan baru. Jika berbeda, lakukan backup terenkripsi, verifikasi backup dapat dipulihkan, lalu migrasikan dengan uninstall, install, dan restore. Jangan menghapus aplikasi lama sebelum backup diverifikasi. IPA iPhone/iPad memerlukan sertifikat dan provisioning Apple yang valid.

Audit APK debug yang tersedia: asset `v1.0.3` memiliki SHA-256 sertifikat `5f127d57d299d0cccc5e113f0dab701f2e06b50377e9d5c5039ba1b26ba16ca9` (versionCode 4), sedangkan build debug lokal `v1.0.4` memiliki `9275962339d380d0cc200881de3b32fdc7f29b401134726a8887b294c6dac9fa` (versionCode 5). Kedua sertifikat berbeda. Sertifikat APK yang benar-benar terpasang pada perangkat pengguna belum dapat diperiksa tanpa APK lama atau perangkatnya.
