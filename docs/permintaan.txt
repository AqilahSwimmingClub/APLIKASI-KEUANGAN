NAMA APLIKASI:
Keuangan Rumah Tangga

TUJUAN:
Aplikasi pengelolaan keuangan rumah tangga pribadi untuk mencatat seluruh pemasukan dan pengeluaran, mengetahui saldo, tabungan, investasi, laporan, serta membandingkan kondisi keuangan bulan berjalan dengan bulan sebelumnya.

PRINSIP UTAMA:
- Mobile-first.
- Full responsive.
- Harus nyaman pada HP portrait/landscape, tablet portrait/landscape, dan desktop.
- Android adalah target utama.
- UI modern, bersih, premium, ringan.
- Bahasa antarmuka: Indonesia.
- Mata uang: Rupiah (Rp).
- Data transaksi menjadi SINGLE SOURCE OF TRUTH.
- Perubahan transaksi harus otomatis memperbarui seluruh Dashboard dan Laporan.
- Jangan membuat data keuangan yang harus dimasukkan ulang di beberapa halaman.
- Jangan menyentuh repository aplikasi ASC atau repository lain.
- Kerjakan hanya repository APLIKASI-KEUANGAN.

23. GIT / GITHUB
==================================================

Karena repository masih kosong:

1. Inisialisasi seluruh project.
2. Buat branch main jika belum ada.
3. Tambahkan .gitignore yang benar.
4. Jangan commit node_modules, build cache, APK lokal, secret, atau file sensitif.
5. Jalankan seluruh test/build.
6. Perbaiki error sampai lolos.
7. Commit hasil.
8. Push ke origin/main.
9. Jalankan/validasi GitHub Actions bila akses memungkinkan.
10. Jika workflow gagal karena kode/configuration, perbaiki dan push lagi.
11. Jangan berhenti setelah sekadar membuat source code jika masih ada error yang dapat diperbaiki.
