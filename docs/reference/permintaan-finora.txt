5. HILANGKAN GARIS BIRU ANEH
==================================================

PENTING:

Pada screenshot terdapat garis biru lurus di ujung kiri dan kanan field Password saat focus.

JANGAN pertahankan efek tersebut.

Audit CSS/DOM/WebView.

Hilangkan atau override:

- default browser outline
- default Android WebView focus ring
- default input highlight
- default appearance yang tidak diperlukan
- focus border bawaan browser
- selection visual yang menyebabkan garis vertikal aneh

Gunakan CSS reset yang aman seperti:

outline: none;
-webkit-appearance: none;
appearance: none;
-webkit-tap-highlight-color: transparent;

Tetapi tetap jaga accessibility.

JANGAN menghilangkan indikasi focus sepenuhnya.

Ganti focus state dengan custom style:

- border biru tipis premium
- glow halus
- soft box-shadow
- transition 180–220ms
- tidak ada garis lurus biru di ujung field

Contoh arah:

border-color:
rgba(37, 99, 235, 0.55)

box-shadow:
0 0 0 3px rgba(37, 99, 235, 0.08),
0 8px 24px rgba(37, 99, 235, 0.08)

Jangan harus menggunakan angka persis jika ada kombinasi visual yang lebih baik.

==================================================
21. ANDROID RELEASE SIGNING
==================================================

Siapkan signing release permanen.

Gunakan GitHub Secrets:

ANDROID_KEYSTORE_BASE64
ANDROID_KEY_ALIAS
ANDROID_KEY_PASSWORD
ANDROID_KEYSTORE_PASSWORD

JANGAN commit keystore.

Workflow:

- decode keystore
- build release APK
- sign dengan keystore tetap
- verify signature
- upload artifact

Jika secrets belum tersedia:

- workflow harus fallback / skip release signing dengan pesan jelas
- debug build tetap boleh tersedia
- jangan klaim signed release selesai
