5. ATURAN PASSWORD — FLEKSIBEL
==================================================

PENTING:

JANGAN memaksa password minimal 10 karakter.

JANGAN mewajibkan:

- huruf besar
- huruf kecil
- angka
- simbol
- kombinasi tertentu

Pengguna bebas memilih password sendiri.

Password boleh:

- angka saja
- huruf saja
- huruf kecil saja
- huruf besar saja
- campuran huruf
- campuran angka dan huruf
- simbol
- kombinasi apa pun

Contoh password yang HARUS diterima:

1
12
1234
123456
abc
ABC
fahmi
FAHMI
Fahmi
fahmi123
ABC123
@123
Ab

Syarat password:

HANYA:
password tidak boleh kosong.

Konfirmasi password:
harus sama persis.

Boleh tampilkan indikator:

Lemah
Sedang
Kuat

Tetapi indikator hanya informasi.

JANGAN memblokir user karena password dianggap lemah.

==================================================
6. KEAMANAN PASSWORD
==================================================

Walaupun password fleksibel:

- jangan simpan plaintext
- jangan log password
- jangan commit credential
- jangan tampilkan password kecuali user menekan show password
- tetap gunakan mekanisme encryption/key derivation yang aman

Menu Ubah Password juga harus mengikuti aturan fleksibel yang sama.

==================================================
7. BACKUP PASSWORD
==================================================

Password backup juga dibuat fleksibel.

JANGAN paksa minimal 10 karakter.

Password backup boleh apa saja selama tidak kosong.

Boleh tampilkan peringatan:

"Password yang lebih panjang lebih aman."

Tetapi user tetap boleh melanjutkan.
