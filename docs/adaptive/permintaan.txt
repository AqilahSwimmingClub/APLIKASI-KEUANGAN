   - Landscape

====================================================
PRINSIP RESPONSIVE — SANGAT PENTING
====================================================

JANGAN membuat UI berdasarkan satu resolusi tetap.

JANGAN sekadar memperbesar tampilan HP pada tablet.

JANGAN menggunakan fixed width/height yang menyebabkan layout rusak pada layar lain.

Gunakan:
- CSS responsive
- CSS Grid
- Flexbox
- clamp()
- minmax()
- responsive typography
- responsive spacing
- container sizing
- media queries/breakpoints
- safe-area-inset

Pastikan layout tidak mengalami:
- horizontal overflow
- teks terpotong
- card bertumpuk
- tombol keluar layar
- grafik kepotong
- bottom navigation menutupi konten.

====================================================
BREAKPOINT / ADAPTIVE LAYOUT
====================================================

Gunakan breakpoint yang masuk akal berdasarkan ruang layar, bukan berdasarkan merek perangkat.

Secara konseptual:

COMPACT:
< 600px

MEDIUM:
600px – 839px

EXPANDED:
>= 840px

Silakan sesuaikan secara teknis jika ada alasan kuat.

====================================================
ANDROID PHONE / IPHONE — PORTRAIT
====================================================

Layout utama:

- grafik full width

- form dapat menggunakan 2 kolom jika nyaman

Tetap jaga ukuran tombol agar mudah disentuh.

Konten harus tetap dapat di-scroll jika tinggi layar kecil.

====================================================
ANDROID TABLET / IPAD — PORTRAIT
====================================================

Gunakan adaptive tablet layout.

Dashboard minimal dapat menggunakan:
- 2 kolom
- summary cards grid
- grafik lebih besar
- transaksi terbaru berdampingan dengan informasi lain jika ruang cukup.

Sidebar/navigation rail harus berubah secara otomatis berdasarkan ukuran layar.

====================================================
ORIENTATION
====================================================

JANGAN lock aplikasi hanya portrait.

Android harus mendukung:
- portrait
- landscape

Tablet harus mendukung:
- portrait
- landscape

iPad harus mendukung:
- portrait
- landscape

iPhone ikuti orientation yang didukung aplikasi/perangkat.

Ketika orientation berubah:
- data tidak boleh hilang
- form tidak boleh reset
- navigation state tidak boleh rusak
- aplikasi tidak boleh crash
- layout harus reflow dengan benar.
